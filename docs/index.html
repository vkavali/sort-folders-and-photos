What it does

Built for photographers, archivists, and anyone who has inherited a mess of exported folders from Google Drive, OneDrive, SD cards, and phone backups.

⤵︎

Flatten or group

Dump everything into one tidy folder, or tick which folder names to keep as destination categories. No predefined list — your names, your categories.

🛡

No duplicates lost

Every file is cryptographically hashed. Exact duplicates are isolated to Duplicates/ so you can review them — never silently dropped.

🕒

Chronological rename

Each photo is renamed with its EXIF capture time in front — so your destination folder sorts itself in perfect chronological order, in any file manager.

✂︎

Split by time

Got one folder that's really two events? Set a time window and files route themselves — Haldi before 2 PM, Sangeet after, Reception the next day.

⏲

Copy by default

Your originals stay untouched unless you explicitly pick Move — and then only after each copy is hash-verified byte-for-byte.

⎌

Graceful cancel

Change your mind mid-run? Cancel halts new work; in-flight copies finish cleanly so no file is ever left half-written.

Why you can trust it

This is a local-only utility. It has no business seeing your network.

No network calls

The app never contacts any server. No telemetry, no analytics, no auto-updater, no crash reporter.

MIT open source

Every line of code is public on GitHub. Read it, audit it, fork it, rebuild it.

Built in public

The Windows installer is assembled by a public GitHub Actions workflow from a specific commit. No hand-uploaded binaries.

Copy by default

The app never deletes your source files unless you explicitly pick Move — and only after every byte is verified.

Using it

Four steps, start to finish.

Drop your folders

Drag the source folder and the destination folder into the app.

Review

Every unique folder name in your source is listed. Tick the ones to keep as categories; ignore the generic containers.

Run

Files copy, hash-verify, and land chronologically named in their destination folders. Progress live. Cancel any time.

Done

Summary shows moved / duplicates / collisions. Open the destination, admire the tidiness.
